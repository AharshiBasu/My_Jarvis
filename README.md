JARVIS

It is a self-sufficient desktop assistant that is able to open youtube, whatsapp, instagram,notepad, cmd, github, google, amazon and many more websites and apps.
This completely works on voice command and can be used to shutdown, restart or sleep your system.
It may cause problem in your system if the locations of the applications does not match thus the os module will not recognize the location.
The code can be motified as per the requirement of the user to shit the location as per their system and the exe files in their system to be opened.
In case the voice is not heard try to speak again as the hearing time is set to 2 seconds. this can be altered as per the requirement of the user.
This is program uses some built in modules along with few modules that need to be installed.
